# Tutorial: How to Use My Visual Search Game
To run this Visual Search Game, you first need to download and install **Mu Editor**, a beginner-friendly Python editor. You can download it from the official website: https://codewith.mu/.
After installing Mu Editor, download my Python code file from this GitHub repository. Open Mu Editor, click the **Load** button, find the downloaded file on your computer, and open it.
Once the code is open, make sure you are using **Python 3 mode**. To select it, click the **Mode** button and choose **Python 3** from the list.
The project uses standard Python libraries, including `tkinter`, `random`, and `time`, to create the game interface, generate random letters, and measure search times. You do not need to install any additional packages if these libraries are already available in your Python installation.
To start the game, simply click the **Run** button in Mu Editor. A new window will open, displaying the first level and the target letter at the top of the screen.
Find the target letter in the grid and click on it as quickly as possible. Complete all ten levels to reach the final results screen, where you can see your individual search times, average time, total time, and number of incorrect clicks.
Enjoy exploring visual attention through this interactive experiment!
